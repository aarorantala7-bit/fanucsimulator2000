# FANUC Simulator 2000

Independent, browser-based educational simulator for FANUC-style programs. Version **v0.61**. Not affiliated with FANUC.

## Run

Open `index.html` in a modern browser (or serve the folder with any static web server). No dependencies or machine connection. Photo import (OCR) needs the folder served over http(s), e.g. `python3 -m http.server`, because browsers block its web worker on `file://`. If the page is opened somewhere that cannot load its `src/` files (for example from a zip in a phone file manager), it shows a notice pointing to the single-file version (`npm run build`) or the https link instead of bare HTML.

## What it does

- **One machine selector** (menu bar, *Machine*): **Milling (0i-MF style, 3-axis)** or **Turning (0i-TF style, 2-axis lathe)**. It switches the simulator and views, the CNC panel, the tool library, the stock setup, the demos and the G/M code library together, and is remembered. Each machine keeps its own editor document.
- **Milling**: G0/G1/G2/G3 (I J or R), G4, G17, G20/G21, G28, G40/G41/G42 cutter compensation (D), G43/G49 (H), G53, G54–G59, G73/G76/G81–G89 drilling cycles, G90/G91, G94/G95, G98/G99, M0/M1/M3/M4/M5/M6/M8/M9/M19/M29/M30. Unknown machine-specific M codes (e.g. M46, M50) are no-ops with a note.
- **Turning**: X is a diameter, U/W incremental, G2/G3 with R or I/K (rear-turret convention: +X up, +Z right), G32, G4, G28/G30, G50 (speed clamp and coordinate setting), G53, G54–G59, G90/G92/G94 (modal), G70/G71/G72/G73/G74/G75/G76 (two-block formats), G96/G97, G98/G99, Txxyy with geometry/wear offsets (X Z R T) and tool nose radius compensation G41/G42.
- **Custom macro B** for both machines: local #1–#33 (per G65 call), common #100–#199 / #500–#999 (retained), arithmetic and functions, IF[..]GOTO / IF[..]THEN, GOTO (forward search first), WHILE[..]DOm / ENDm, G65 argument mapping, M98/M99, nesting limits, system variables (#3000, #3006, #3901, #4001…, #5001…, #5021…, #5061… skip position, #5201… work offsets, tool offsets), PRM[], G10 L2 / L10–L13 / P / L52.
- **G31 skip** (mill and lathe): a one-shot feed move that stops where the tool touches the simulated material: the mill height-field blank with all earlier cuts (tool radius and shape, e.g. the T12 Ø6 ball probe, which never cuts), or the lathe's turned profile (insert outline with its nose radius). The skip position is written to #5061–#5066 in work coordinates (mill X Y Z; lathe X as a diameter, Z) and the following blocks continue from there. **Without contact the move runs its full distance and #5061+ hold its end point** (standard FANUC behaviour; real probing macros check for this). Playback, the block counter and the HUD (`G31 SKIP · CONTACT`) show the stop; the diagnostics list each skip. G31 moves are not used to size the auto stock; for a program that only probes, set the stock size in the stock dialog.
- **Parameters** (Setup › Parameters or CNC panel SYSTEM): rapid type 1401 LRP, rapid rates 1420, F0 1421, max feed 1422, jog 1423/1424, reference 1240, stroke limits 1320/1321, accel time constants 1620/1622, DPI 3401, power-on G01 3402, spindle clamp 3772, cycle parameters 5130–5143. Changes made by a program (G10 L52) take effect from that block on.
- **Real-time playback** from programmed feeds and rapid rates with feed (0–150 %), rapid (F0/25/50/100 %) and spindle overrides, single block, optional stop (M01), block skip (/), dwell and cycle time estimate. Step, the step counter and the scrubber work per NC block; the tool moves smoothly inside a block (time-based per frame). Arcs are split adaptively (chord error ≤ 0.01 mm mill, 0.005 mm lathe) and collinear moves are merged for drawing.
- **Tools and stock**: editable mill tools (diameter, corner radius, flute and overall length, point angle; H/D offsets) and lathe inserts (ISO shape C/D/V/W/T/S/R, nose radius, tip T0–T9, holder angle, groove/thread width), saved in the browser with reset. Lathe stock is a solid bar or a tube (OD, bore, length, face). Material removal uses the actual tool outline. **Auto stock** (default for opened or pasted programs): sized from feed moves at or below Z0 (rapids, G28/home and air moves ignored) plus the tool radius, then a margin (Stock dialog, default 10 %); lathe OD from the largest cut diameter, length from the cut Z range. *Keep manual size* turns it off. Demos keep their own stock. **Work zero**: the stock dialogs set where program zero sits on the blank: mill X0 Y0 at the stock centre (default), the front-left corner, a custom position or where the program cuts (auto size), and Z0 on the top surface or a set depth below it; lathe X0 is the spindle centreline and Z0 the finished part face (default), the stock front end or a custom stock-front Z. Auto size keeps the chosen zero. The G54 fields in the dialogs are the same work offset table as OFS/SET › WORK (they move G28/G53 positions, not the blank).
- **Threads** (lathe G32/G92/G76, OD and ID): the revolved view draws the helix at the lead over the threaded length with root/crest shading at the real depth; the XZ section shows the 60° profile down to the minor diameter.
- **Views**: drag rotates the mill view and pans the lathe views; on touch screens two fingers pinch-zoom and pan every view (the page itself does not zoom or scroll). Double-click resets the mill view.
- **CNC panel** (Program › CNC Panel): POS / PROG / OFS/SET / SYSTEM / MESSAGE screens, EDIT / MEM / MDI / JOG / HANDLE / REF modes, CYCLE START / FEED HOLD / RESET, word-based INSERT / ALTER / DELETE, CAN, EOB, O-number and word search, program directory.
- **Import from photo** (File): take photos of the control's program screen with the phone camera or pick images. Several pages are kept in order and can be reordered. OCR runs in the browser with the vendored Tesseract.js, which loads only when used; nothing is uploaded. NC-aware cleanup fixes O/0, I/1, S/5, B/8 and Z/2 using the word grammar, and strips screen line numbers, status rows, soft-key bars and cursor marks. Lines repeated across consecutive pages are dropped. You check and edit the text in a preview, then it is appended after the last imported block.
- **WinCAM / NC files** (File): import Camtek WinCAM `.cnc` programs (also `.nc`, `.txt`, `.ncc`; windows-1252 or UTF-8). Export writes the program back as WinCAM text (CRLF, `%` lines, an O-number line with a comment). An imported file exports byte for byte. On import, the program's tools are listed in the tool table: the T number, the H/D numbers used (mill) or the Txxyy offset numbers (lathe), the first block that calls each tool, and a name from a comment right after the call. Tool geometry stays at the defaults for you to edit.
- **Macros menu** (menu bar, *Macros › Insert macro…*): a library of Custom Macro B templates for the selected machine, each with a short description, an example setup and a parameter form with working defaults. Milling: bolt-hole circle, rectangular pocket, circular pocket, facing pattern, peck drilling loop, edge probe (G31); turning: OD multi-pass roughing loop, grooving loop, thread repeat (G92 passes), face probe (G31); both: part counter (#3901/#3902). *G65 call + subprogram* puts `G65 P9xxx …` at the cursor line and appends `O9xxx … M99` after the main program (before the final `%`), using the next O number not in the program or the CNC program directory; *Inline* writes the arguments as `#` assignments plus the body at the cursor, with GOTO labels that do not clash with N numbers already in the program. Coordinates are in the active work offset (G54…), so the macros follow the work zero and G54 set in the stock dialog. The probing templates (mill X edge with the T12 ball probe, lathe face) use G31 and store the measured values from the skip position #5061+ in #140–#143. *Save as my macro…* stores your own macro (arguments as G65 letters, body with `{X}` for the argument's variable, `{L1}` labels and `{D1}` loop numbers) in this browser; *Export / Import my macros* writes or reads a `fanucsim-macros` JSON file. Works in the text editor and in the CNC panel (EDIT mode only).
- **G/M code library** (Help) with separate Milling and Turning entries, realistic examples and address tables.

## Project layout

- `src/nc/`: machine data and parameters, macro executor, offset geometry, G31 contact search (`skip.js`).
- `src/simulation/`: mill interpreter and stock. `src/lathe/`: lathe interpreter, removal model and view.
- `src/sim/runtime.js`: shared real-time playback clock.
- `src/renderer/`: CPU, GPU and viewport drawing. `src/tools/`: mill tool library.
- `src/import/`: OCR text cleanup and page de-dupe (`nc-cleanup.js`), WinCAM import/export and tool list (`wincam.js`). `src/ui/import-dialog.js`: the import/export UI.
- `src/macros/templates.js`: macro template library, rendering, O/N clash checks, my-macros import/export. `src/ui/macro-menu.js`: the Macros dialog.
- `src/ui/`: menus, CNC panel, machine selector, code library, demos, HUD.
- `vendor/`: Tesseract.js, its WASM core and English model (Apache-2.0, see `vendor/README.md`).
- `tests/`: `npm test` (source checks + node:test unit tests); `tests/headless_check.py`, `tests/headless_import.py` and `tests/headless_macros.py` browser checks (python playwright + Chrome).

Ordered classic scripts with shared state; the simulation modules are UMD so the tests run them in Node.

## Limitations

Educational visualization only: no machine control, no collision checking, no certified tool data. The mill stock is a height field, the lathe stock a per-Z radius profile. Thread milling and tapping (G84) on the mill are not drawn as threads (deferred). Behaviour follows the FANUC 0i manuals as closely as practical, but machine builders change many details (M codes, parameters, G code system); always check against your machine's documentation.
